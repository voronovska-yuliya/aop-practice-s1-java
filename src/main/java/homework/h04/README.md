1\. Навіщо в програмуванні окремий тип для «так» і «ні»? Тип boolean потрібен для зберігання лише двох значень: true (так) і false (ні). Він використовується для перевірок та умов.



2\. Як сказати !(a \&\& b) людською мовою? Це означає: «Неправда, що і a, і b одночасно істинні». Тобто хоча б одна з умов хибна.



3\. Чим \&\& відрізняється від \&? \&\& перевіряє другу умову лише тоді, коли перша істинна. \& для логічних значень перевіряє обидві умови, а для цілих чисел виконує побітову операцію.



4\. Чому програма не падає в if (x != null \&\& x.name == «Іван»), хоча x порожній? Тому що \&\& зупиняється, якщо перша умова хибна. Якщо x == null, друга умова не перевіряється, тому помилки не виникає.



5\. Як запхати 32 відповіді «так/ні» в одне число? Можна використати 32 біти числа, де кожен біт відповідає за одну відповідь: 1 — так, 0 — ні.



6\. Що швидше: n % 2 чи n \& 1? n \& 1 перевіряє останній біт числа, а n % 2 обчислює залишок від ділення. Побітова операція може бути швидшою, але сучасний компілятор часто оптимізує обидва варіанти.
