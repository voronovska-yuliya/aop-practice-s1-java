1\. Навіщо потрібні окремі типи для цілих і дробових чисел? Цілі числа зберігають числа без дробової частини, а дробові — числа з частиною після коми. Вони відрізняються способом зберігання та точністю обчислень.



2\. Що означає «рухома кома» і куди вона рухається? Це спосіб запису дуже великих або малих чисел, коли кома умовно переміщується, а її положення задається степенем числа 10 або 2.



3\. Скільки цифр після коми комп’ютер здатен запам’ятати? Це залежить від типу даних. Наприклад, float має приблизно 7 значущих цифр, а double — приблизно 15–16 значущих цифр.



4\. Чому 0.1 + 0.2 не дорівнює 0.3? Тому що комп’ютер не може точно представити деякі десяткові дроби у двійковому форматі, через що виникає невелика похибка.



5\. Чому гроші ніколи не зберігають у double? Тому що double може давати похибки в обчисленнях. Для грошей краще використовувати цілі числа в копійках або тип BigDecimal у Java.



6\. Чи може число не дорівнювати саме собі? Так. У комп’ютері існує спеціальне значення NaN («не число»), яке не дорівнює навіть самому собі.
