1\. Навіщо масив, якщо можна завести сто окремих змінних? Масив дозволяє зберігати багато значень одного типу під однією назвою та легко обробляти їх за допомогою циклів.



2\. Що таке індекс і чому програма падає з index out of bounds? Індекс — це номер елемента в масиві. Помилка виникає, коли звертаються до індексу, якого не існує.



3\. Чому розмір звичайного масиву не можна змінити після створення? Тому що під час створення масиву для нього виділяється пам’ять певного розміру. Щоб змінити розмір, потрібно створити новий масив.



4\. Чому прохід по рядку 2D-масиву швидший за прохід по колонці? Тому що елементи рядка зазвичай розташовані поруч у пам’яті, тому процесору швидше їх обробляти.



5\. Чому масиви нумеруються з нуля, а не з одиниці? Тому що індекс показує зміщення від початку масиву: перший елемент має зміщення 0.



6\. Чому додати елемент у кінець масиву дешево, а на початок — дорого? У кінець елемент можна додати без переміщення інших елементів, якщо є вільне місце. На початок потрібно зсунути всі інші елементи вправо.
