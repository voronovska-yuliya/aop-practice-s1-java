1\. Як знайти найбільше число в масиві? Взяти перший елемент за найбільший і пройти масив, замінюючи його, якщо знайдеться більше число.



2\. Чому майже кожна задача на масив починається з одного проходу циклом? Тому що за один прохід можна перевірити всі елементи й часто розв’язати задачу без зайвих обчислень.



3\. Що має робити код, якщо масив порожній? Перевірити, чи масив порожній, і не намагатися отримати його елементи. За потреби повернути повідомлення або спеціальне значення.



4\. Як за один прохід знайти найкращий день купити й найкращий продати акції? Зберігати найнижчу ціну, яку вже зустріли, і найбільший можливий прибуток. Для кожного наступного дня перевіряти, скільки можна заробити, продавши акції за поточною ціною.



5\. Тисяча запитів «яка сума чисел з 10-го по 1000-й?» — як відповідати миттєво? Використати формулу суми арифметичної прогресії замість додавання кожного числа окремо.



6\. Чи корисно вчити готові прийоми, чи вони заважають думати самому? Корисно, тому що готові прийоми допомагають швидше розв’язувати типові задачі. Але важливо розуміти, як вони працюють і коли їх застосовувати.
