### Java Template Repository

## Основні команди

### Compile

```shell

mvn compile

```

### Clean

```shell

mvn clean

```

### Test

```shell

mvn test

```

### Reformat code

```shell

mvn spotless:apply

```

### Check formatting

```shell

mvn spotless:check

```

## Як запустити

1. Переконайтеся, що встановлено Java та Maven.

2. Відкрийте термінал у кореневій папці проєкту.

3. Завантажте залежності та зберіть проєкт:

```bash

mvn clean install

```

4. Запустіть тести:

```bash

mvn test

```
