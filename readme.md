### Java Template Repository

## Основні команди

### Compile

mvn compile

### Clean

mvn clean

### Test

mvn test

### Reformat code

mvn spotless:apply

### Check formatting

mvn spotless:check

## Як запустити

1. Переконайтеся, що встановлено Java та Maven.

2. Відкрийте термінал у кореневій папці проєкту.

3. Завантажте залежності та зберіть проєкт:

mvn clean install

4. Запустіть тести:

mvn test
