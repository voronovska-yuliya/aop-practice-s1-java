
# Практична робота №12 — Алгоритми сортування

## Виконані завдання

1. Height Checker — визначення кількості учнів, які стоять не на своїх місцях порівняно з відсортованим масивом. Для цього створюється копія масиву, сортується та порівнюється з початковим.

2. Relative Sort Array — сортування одного масиву відповідно до порядку елементів другого масиву. Використано Counting Sort: підрахунок кількості кожного числа та формування результату в потрібному порядку.

## Відкрита дискусія

1. Як людина сортує карти в руці?

Людина бере одну карту та вставляє її на правильне місце серед уже впорядкованих карт. Такий принцип використовується в алгоритмі сортування вставками (Insertion Sort).

2. Що означає сортування in-place?

Це означає, що алгоритм змінює елементи безпосередньо в початковому масиві, не створюючи ще один великий масив для результату. Тобто використовує мінімум додаткової пам'яті.

3. Чому порівняльне сортування не може бути швидшим за O(n log n)?

Для загального випадку порівняльного сортування існує нижня межа Ω(n log n), оскільки алгоритм має порівнювати елементи, щоб визначити їхній порядок. Але Counting Sort не належить до порівняльних алгоритмів, тому може працювати швидше за певних умов.

4. Чому не варто завжди писати власне сортування?

Тому що в мовах програмування вже є готові оптимізовані та перевірені методи сортування. Власний алгоритм варто реалізовувати, коли цього вимагає задача або потрібно краще зрозуміти принцип роботи алгоритмів.

5. Чому під час сортування таблиці за прізвищем і містом важливо правильно задати критерії?

Тому що спочатку потрібно сортувати за прізвищем, а якщо прізвища однакові — за містом. При цьому всі дані одного запису повинні залишатися разом, щоб не порушити відповідність інформації.

6. Як відсортувати мільйон оцінок від 1 до 12 швидше за Quick Sort?

Можна використати Counting Sort. Для цього створюється масив із 12 комірок, у якому підраховується кількість кожної оцінки. Потім числа записуються в початковий масив у правильному порядку. Складність такого алгоритму — O(n + k), де k = 12.
