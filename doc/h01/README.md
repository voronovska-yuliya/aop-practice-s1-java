1\. Чим програма відрізняється від алгоритму? Алгоритм — це послідовність дій для розв’язання задачі, а програма — це алгоритм, записаний мовою програмування.



2\. Навіщо потрібні мови програмування, якщо процесор їх усе одно не розуміє? Вони потрібні, щоб людині було зручно писати команди, які потім перекладаються у зрозумілий процесору машинний код.



3\. Чи може комп’ютер зробити щось, чого йому не казали? Комп’ютер може виконувати дії, які прямо не вказані, але передбачені програмою. Самостійно виходити за її межі він не може.



4\. Чи є рецепт борщу алгоритмом? Так, тому що він містить послідовність дій, які потрібно виконати для отримання результату.



5\. Опишіть, як зав’язати шнурки, для того, хто ніколи їх не бачив. Візьми два кінці шнурка, перехрести їх і протягни один під іншим. Затягни. Зроби петлю з одного кінця, обгорни її другим кінцем і протягни його крізь утворений отвір. Потягни за обидві петлі, щоб закріпити вузол.



6\. Програма правильно порахувала всі приклади з дошки. Чи це доводить, що вона працює? Ні, тому що вона могла правильно розв’язати лише ці приклади, але мати помилки в інших випадках. Потрібно перевірити її на різних вхідних даних.
