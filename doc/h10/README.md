\# Практична робота №10 — Рекурсія



1\. \*\*Що таке рекурсія?\*\*



Рекурсія — це коли метод викликає сам себе для розв’язання задачі.



2\. \*\*Навіщо рекурсії базовий випадок?\*\*



Базовий випадок потрібен, щоб зупинити рекурсію. Без нього метод викликатиме себе нескінченно, що може призвести до StackOverflowError.



3\. \*\*Де рекурсія трапляється поза програмуванням?\*\*



Наприклад, у сімейному дереві, вкладених папках на комп’ютері або матрьошках.



4\. \*\*Що станеться, якщо функція викличе сама себе й забуде зупинитися?\*\*



Кількість викликів постійно зростатиме, доки не переповниться стек і не виникне StackOverflowError.



5\. \*\*Чому 50-те число Фібоначчі рахується довго, а після маленької правки — миттєво?\*\*



Звичайна рекурсія багато разів обчислює однакові значення. Якщо зберігати вже обчислені результати, їх не потрібно рахувати повторно, тому програма працює значно швидше.



6\. \*\*Рекурсія чи цикл, якщо працює і те, і те?\*\*



Для звичайного повторення частіше зручніший цикл. Рекурсія краще підходить для роботи з деревами та вкладеними структурами. Вибір залежить від задачі
