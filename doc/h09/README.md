1\. Навіщо виносити код у функцію, якщо він і так працює? Щоб не повторювати однаковий код, зробити програму зрозумілішою та мати можливість використовувати цю функцію в різних місцях.

2\. Чим параметр відрізняється від аргументу? Параметр — це змінна, яка вказується під час оголошення функції. Аргумент — це конкретне значення, яке передається функції під час її виклику.

3\. Чому функція «бачить» не всі змінні програми? Тому що в Java діє область видимості змінних. Локальні змінні доступні лише в тому методі або блоці, де вони оголошені.

4\. Якої довжини має бути функція? Фіксованої довжини немає. Головне, щоб функція виконувала одну зрозумілу задачу і її було легко читати та перевіряти.

5\. Функція змінила переданий масив, хоча цього не просили. Як так? У Java масив передається у функцію через копію посилання на нього. Тому зміни його елементів впливають на початковий масив.

6\. Що функція має повернути, якщо нічого не знайшла? Це залежить від задачі. Наприклад, можна повернути -1, null або порожню колекцію. Головне — заздалегідь визначити, як позначається відсутність результату.
