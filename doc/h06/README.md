1\. Як комп’ютер зберігає літеру, якщо вміє зберігати тільки числа? Кожній літері відповідає числовий код, який комп’ютер зберігає у двійковому вигляді.



2\. Чому ‚A‘ і «A» — це різні речі? ‚A‘ — це один символ, а «A» — рядок, який містить цей символ.



3\. Чим порожній рядок відрізняється від відсутнього? Порожній рядок «» існує, але не містить символів. Відсутнє значення null означає, що рядок не заданий.



4\. Звідки беруться «кракозябри» замість тексту? Вони виникають, коли текст зчитується з неправильним кодуванням, через що байти перетворюються на неправильні символи.



5\. Скільки літер у смайлику 👨‍👩‍👧? Це один видимий смайлик, але він складається з кількох символів Unicode, об’єднаних спеціальними символами.



6\. Чому слово «Привіт» у файлі важить більше, ніж «Hello»? Тому що українські літери в UTF-8 зазвичай займають по два байти, а англійські — по одному. Тому «Привіт» займає більше місця.
